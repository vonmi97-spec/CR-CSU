# CR CSU

Application Android de prise de notes horodatées pour les comptes-rendus du CSU.

- Sections, comptes-rendus, évènements (boutons rapides, texte, photo, vidéo, mémo vocal, position GPS)
- Validation automatique ou manuelle des évènements
- Catégories / actions, 9 boutons personnalisables, rappels (notifications)
- Export PDF, CSV, DOC, email ; multi-export ; export protégé par code
- Sauvegarde / restauration (fichier .json)

L'APK est compilé automatiquement par GitHub Actions à chaque push :
onglet **Releases** → `CR-CSU.apk`.
